## 怎么用 ScraperAPI 抓取亚马逊ASIN数据

实际操作比我预想的简单。注册后拿到 API Key，三种用法任选：

### 方法一：直接 API 调用

最基础的方式。把亚马逊商品页 URL 作为参数传进去：

```
GET https://api.scraperapi.com?api_key=你的KEY&url=https://www.amazon.com/dp/B09V3KXJPB&country_code=us
```

返回完整 HTML，你自己解析。适合已经有解析逻辑的团队。

### 方法二：Amazon Structured Data Endpoint

这是我最常用的。直接传 ASIN，返回 JSON：

```
GET https://api.scraperapi.com/structured/amazon/product?api_key=你的KEY&asin=B09V3KXJPB&country=us
```

返回的 JSON 里字段很全：`name`、`price`、`rating`、`reviews_count`、`brand`、`availability`、`variants 等等。省掉了写解析器的时间。

### 方法三：异步批量模式

ASIN 列表超过几百个的时候，我用异步模式。把一批 URL 提交上去，ScraperAPI 在后台跑完后通过 webhook 通知我取结果。不占本地线程，适合大规模采集。
